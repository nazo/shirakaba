# Contributing

Shirakaba is an experiment maintained by one person, and its design still changes without
notice.

- **Issues are welcome**: bug reports, questions, friction you met while building something,
  and ideas. For a bug, include the package, the version or commit, and the smallest code that
  shows it.
- **Pull requests from outside are not accepted** for now. If you have a fix in mind, describe
  it in an issue; pull requests are closed without review.
- **Vulnerabilities** are reported privately; see [SECURITY.md](SECURITY.md).

The conventions and checks for working on the code are in [AGENTS.md](AGENTS.md).
