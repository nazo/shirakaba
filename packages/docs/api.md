- `Shirakaba\Runtime\RoadRunner\RoadRunnerRuntime` (class, `runtime-roadrunner/src/RoadRunnerRuntime.php`): Runs an application as a RoadRunner HTTP worker: the application is built once and serves requests until RoadRunner stops the worker (design/03-runtimes-and-scopes.md).

## shirakaba/session

- `Shirakaba\Session\CsrfProtection` (class, `session/src/CsrfProtection.php`): Rejects cross-site requests that change state (POST, PUT, PATCH, DELETE).
- `Shirakaba\Session\FileSessionStore` (class, `session/src/FileSessionStore.php`): Stores each session as a JSON file.
- `Shirakaba\Session\InMemorySessionStore` (class, `session/src/InMemorySessionStore.php`): Keeps sessions in process memory: for tests, or a single worker process.
- `Shirakaba\Session\JsonData` (class, `session/src/JsonData.php`): Session data as JSON, the format every session store keeps, so a store never PHP-serialises data (a stolen store cannot inject objects).
- `Shirakaba\Session\Session` (class, `session/src/Session.php`): The session of one request, kept in the RequestScope (never in globals, design/03-runtimes-and-scopes.md).
- `Shirakaba\Session\SessionMiddleware` (class, `session/src/SessionMiddleware.php`): Loads the session for each request into the RequestScope and saves it afterwards.
- `Shirakaba\Session\SessionStore` (interface, `session/src/SessionStore.php`): Where session data lives between requests.
- `Shirakaba\Session\SetCookie` (class, `session/src/SetCookie.php`): A Set-Cookie header with secure defaults: Secure, HttpOnly, SameSite=Lax, Path=/.
- `Shirakaba\Session\Testing\SessionStoreChecks` (class, `session/src/Testing/SessionStoreChecks.php`): What every SessionStore must do, as a list of problems so any test framework can assert on it.
