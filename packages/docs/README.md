# shirakaba/docs

The Shirakaba guide, design documents and API index, installed with an application
so coding agents read documentation that matches the installed version ([static analysis and agents](design/13-static-analysis-and-agents.md)). Start at
[index.md](index.md).

`vendor/bin/shirakaba-docs agents:sync` writes a short block into the project's `AGENTS.md`
that points agents here.
